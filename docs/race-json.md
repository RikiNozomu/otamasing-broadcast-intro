# รูปแบบไฟล์ JSON ของรายการแข่ง

ไฟล์นี้ใช้ทั้งตอน **นำเข้า JSON** (เลือกไฟล์ หรือกด **วาง JSON** แล้ววางข้อความ) และ **ส่งออก** (บันทึกไฟล์ หรือ **คัดลอก JSON**; dock ใน OBS บันทึกไฟล์ไม่ได้ ให้ใช้คัดลอก) ใน dock ถ้าจะให้ Claude แปลงข้อมูลจากหน้าเว็บ (เช่น netkeiba) ให้แปะเอกสารนี้ หรือ [`schema/race.schema.json`](../schema/race.schema.json) ไปด้วย แล้วบอกว่า "แปลงเป็น JSON ตามรูปแบบนี้"

- ไฟล์ทั้งไฟล์ต้องเป็น object ที่มี `races` (อาร์เรย์ของรายการ) และ/หรือ `horses` (ข้อมูลม้า ดู [ข้อมูลม้า](#ข้อมูลม้า-horses)) หรือจะเป็นอาร์เรย์ของรายการเฉยๆ ก็ได้
- ช่องที่ไม่ใส่จะใช้ค่าเริ่มต้นในตาราง ช่องที่ **ต้องมี** มีแค่ `date`, `name` และ `runners`
- ตอนนำเข้าเลือกได้ว่าจะ **เพิ่มต่อ** (รายการที่ วัน + สนาม + เลขรอบ ตรงกับของเดิมจะถูกแทนที่) หรือ **แทนที่** (แทนที่เฉพาะส่วนที่มีในไฟล์: ไฟล์ที่มีแค่รายการแข่งจะแทนที่รายการแข่งทั้งหมดแต่ม้ายังอยู่ ไฟล์ที่มีแค่ม้าก็แทนที่แค่ม้า)
- ตัวรูปไม่อยู่ในไฟล์ ไฟล์เก็บแค่ **ชื่อรูป** แบบ `image/ปีเดือนวันชั่วโมงนาทีวินาทีมิลลิวินาที.นามสกุล` เช่น `image/20261106031451123.jpg` รูปทุกรูปที่เลือกใน dock จะถูกเก็บไว้ในเบราว์เซอร์เครื่องนั้นด้วยชื่อนี้ (รูปฉากหลังของการ์ดและหน้าผล, รูปม้า, รูปสีเสื้อที่อัป, BG หน้าแรก)
- ถ้าจะย้ายข้อมูลพร้อมรูปไปอีกเบราว์เซอร์ (เช่นเตรียมใน Chrome แล้วเอาเข้า OBS) ให้กด **บันทึก .zip พร้อมรูป** ในแผงส่งออก จะได้ไฟล์ .zip ที่มี `data.json` (JSON เดียวกับด้านล่าง) และไฟล์รูป `image/…` ตามชื่อใน JSON แล้วนำเข้า .zip นั้นที่ปุ่มนำเข้า รูปจะถูกเก็บในเครื่องนั้นก่อนนำเข้าข้อมูล (dock ใน OBS บันทึกไฟล์ไม่ได้ จึงส่งออก .zip จาก OBS ไม่ได้)
- ตอนนำเข้า ถ้าชื่อรูปไหนไม่มีในเครื่องนี้หรือไฟล์รูปเสีย จะมีแจ้งเตือนบอกชื่อรูป แล้วเอาชื่อนั้นออกจากข้อมูลที่นำเข้า (ข้อมูลส่วนอื่นยังเข้าครบ)
- ลบรูป เปลี่ยนรูป หรือลบรายการ/ม้าใน dock จะลบไฟล์รูปในเครื่องด้วย ยกเว้นรูปที่ยังมีที่อื่นใช้อยู่

ตัวอย่างเต็มอยู่ที่ [`example-race.json`](example-race.json)

## ระดับไฟล์

| ช่อง | ชนิด | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `version` | `1` | `1` | รุ่นของรูปแบบไฟล์ |
| `races` | อาร์เรย์ของรายการ | `[]` | รายการแข่ง เรียงตามลำดับที่จะแสดงในหน้าแรก (ต้องมี `races` หรือ `horses` อย่างน้อยอย่างหนึ่ง) |
| `horses` | อาร์เรย์ของม้า | `[]` | ข้อมูลม้าของแท็บ **ม้า** |
| `horseSettings` | object | – | `currency`: สกุลเงินรางวัลที่แสดง (`"own"` = ตามม้าแต่ละตัว หรือรหัสสกุลเงิน), `rates`: ค่าของ 1 หน่วยเป็น USD เช่น `{ "JPY": 0.0066 }` |
| `home` | object | – | ค่าของหน้าแรก: `title`, `subtitle` (วันที่), `highlight` (id ของรายการที่ไฮไลต์ หรือ `null`), `page` (หน้าที่แสดง เริ่มที่ 0, หน้าละ 8 รายการ), `background` (ชื่อรูป BG หรือ `null`), `showCourse` (แสดงคอลัมน์สนาม ค่าเริ่มต้น `true` ขึ้นเมื่อมีรายการที่ใส่สนาม), `showDate` (แสดงคอลัมน์วันที่ แบบ 2026.10.31 ค่าเริ่มต้น `true`) |
| `active` | string | – | สิ่งที่ขึ้นจอ ตอนนำเข้าไม่ใช้ค่านี้: หลังนำเข้าจอจะไปหน้าแรกเสมอ ยกเว้นถ้าเปิดหน้าเปล่าอยู่จะคงหน้าเปล่าไว้ ค่าที่เป็นไปได้: `"home"` หน้าแรก, `"blank"` หน้าเปล่า, `id` ของรายการ (การ์ดรายชื่อม้า), `"<id>:result"` (หน้าผลของรายการนั้น) หรือ `"horse:<id ม้า>"` (หน้าข้อมูลม้า) |
| `transition` | `"wipe"` `"slide"` `"fade"` `"none"` | – | ทรานซิชันตอนเปลี่ยน Active |

รหัสประเทศเป็น ISO 3166 แบบ 2 ตัวอักษร ชุดที่ dock มีให้เลือก (ตรงกับ component "flag" ใน Figma) คือ

รหัสอื่นก็ใช้ได้ (ธงมาจาก flag-icons ครบทุกประเทศ) แค่ไม่อยู่ในตัวเลือกของ dock

## หน้าผลการแข่งขัน

หน้าผลแสดง POS, NO., DRAW (ถ้าเปิดไว้), HORSE, JOCKEY, TIME, MARGIN ได้สูงสุด 10 แถว เรียงตาม `finish`
แล้วต่อด้วยม้าที่ DNF, DQ และ SCR (ช่อง POS ขึ้นตัวอักษรแทนอันดับ ไม่มีเวลาและระยะห่าง)
ม้าที่ล็อค (`result.locked`) อยู่บนสุดทุกหน้าพร้อมแถบเหลือง แถวที่เหลือเปลี่ยนตามหน้า เช่น มีผล 17 ตัวและล็อค 3 อันดับแรก:
หน้า 1 = อันดับ 1–3 + 4–10, หน้า 2 = อันดับ 1–3 + 11–17 ถ้ามีหลายหน้าและเปิด `result.auto` (ค่าเริ่มต้นปิด) หน้าจะวนเองทุก `result.seconds` วินาที

## ข้อมูลม้า (`horses[]`)

หน้าข้อมูลม้า: รูปม้าซ้ายจอ 1/3, ธงประเทศที่ฝึก + ชื่อม้า, "SIRE – DAM (by BMS)", O เจ้าของ / T เทรนเนอร์
หน้า 1 เป็นข้อมูลม้า หน้า 2 เป็น Pedigree 3 รุ่น (มีเมื่อใส่ `sire` หรือ `dam`) หน้าต่อไปเป็นผลงานหน้าละ 7 รายการ เรียงจากใหม่ไปเก่า (เรียงให้เองตาม `date`) รูปม้า (ใส่ได้หลายรูป วนเอง) และรูปสีเสื้อที่อัปไม่อยู่ในไฟล์ แต่ละหน้ามีหัวข้อ PROFILE, PEDIGREE, RACE RECORD
ตอนนำเข้าแบบเพิ่มต่อ ม้าที่ชื่อ (หรือ `id`) ตรงกับของเดิมจะถูกแทนที่ ช่องที่ต้องมีคือ `name`

| ช่อง | ชนิด | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `id` | string | สร้างให้ | รหัสม้า |
| `name` | string | (ต้องมี) | ชื่อม้า |
| `trainedIn` / `bornIn` | รหัสประเทศ 2 ตัว | `""` | ประเทศที่ฝึก (ธงหน้าชื่อ) / ประเทศเกิด |
| `foaled` | `"YYYY-MM-DD"` | `""` | วันเกิด |
| `coat` | `"Bay"` `"Dark Bay"` `"Brown"` `"Black"` `"Chestnut"` `"Dark Chestnut"` `"Grey"` `"White"` หรือ `null` | `null` | สีขน (มีกรอบสีขนบนจอ) |
| `sex` | `"M"` `"F"` `"G"` หรือ `null` | `null` | เพศ: ผู้ (แสดง COLT ถึงอายุ 4 ปี, HORSE ตั้งแต่ 5 ปี), เมีย (FILLY / MARE), ตอน (GELDING) |
